# Font licenses

Champion Tour embeds the following Google Fonts families:

- **Fredoka** — SIL Open Font License 1.1  
  Source and license: https://github.com/google/fonts/tree/main/ofl/fredoka
- **Nunito Sans** — SIL Open Font License 1.1  
  Source and license: https://github.com/googlefonts/NunitoSans

The font binaries in this directory are used without modification. The SIL Open
Font License permits bundling and embedding the fonts with software. The full
license text is available in each linked upstream repository.
