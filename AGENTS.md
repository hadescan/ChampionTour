# Champion Tour Agent Rules

This repository is the single source of truth.

Before implementing ANY feature:

1. Read every file inside ChampionTourDocs.
2. Treat ChampionTourDocs as the official Game Design Document.
3. Never invent gameplay systems.
4. Never redesign existing mechanics.
5. Preserve existing UX.
6. If documentation conflicts with code, documentation wins.
7. Explain implementation plan before coding.
8. After implementation list modified files.
9. Keep code modular and Unity-ready.
