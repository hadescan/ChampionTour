# 09_UI_UX_GUIDE
UI Principles:
- Rounded corners
- Pastel colors
- Large icons
- Consistent spacing
- Premium animations
- Information panel always visible
- No debug text in release builds.

## Locked Gameplay Screen

- `CT-Cozy-Academy-Master-Gameplay-Reference.png` is the required geometry,
  density, hierarchy and art-direction reference.
- The primary viewport is 390 × 844; 360 × 800 and 430 × 932 must preserve the
  same composition.
- Normal Orders use open, boxless customer compositions.
- Requested items use individual warm-gold interactive surfaces.
- Producers are larger than normal items and carry a non-numeric lightning
  identity badge.
- The 1–2–4–8–16 selector is one circular physical Energy button shown only
  for a selected producer.
- Pixel-art and stacked legacy theme overrides are not production UI.
