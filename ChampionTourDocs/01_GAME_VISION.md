# 01_GAME_VISION.md

# Champion Tour – Game Vision
Version 1.0

## Purpose

This document defines the identity of Champion Tour.
Every future design decision must support this vision.

---

# Vision Statement

Champion Tour is a premium, relaxing merge game where players rebuild the world's greatest sports academy one improvement at a time.

The experience should feel satisfying, rewarding and emotionally positive rather than stressful.

---

# Player Fantasy

The player is not simply merging objects.

The player is:

- Managing a sports academy
- Discovering new equipment
- Training future champions
- Restoring forgotten facilities
- Building a beautiful academy

Every completed order should feel like progress toward rebuilding the academy.

---

# First Release Scope

The first playable version includes only:

- Football Academy
- One producer progression
- Complete football item chains
- Academy renovation
- Coins
- Diamonds
- Energy
- Orders
- Merge Board

No additional sports until Football Academy is fully complete.

---

# Design Pillars

1. Relaxing
No timers that create anxiety.

2. Progress
Every session should unlock or improve something.

3. Visual Satisfaction
Merging must feel premium through animation and polish.

4. Simplicity
Easy to learn.
Hard to master.

5. Long-Term Growth
The academy should visibly evolve.

---

# Core Gameplay Loop

Open Game
↓
Collect Items
↓
Merge
↓
Complete Orders
↓
Earn Coins & Producer XP
↓
Upgrade Producer
↓
Earn Diamonds
↓
Renovate Academy
↓
Unlock New Goals

---

# Player Motivation

Short-term:
- Complete next order
- Create next item
- Upgrade producer

Medium-term:
- Finish football academy
- Renovate facilities

Long-term:
- Unlock additional sports
- Build the ultimate sports campus

---

# Reference Philosophy

Inspired by:
- Satisfying progression
- Relaxed pacing
- Incremental upgrades

Champion Tour must NOT copy:
- Artwork
- UI
- Characters
- Icons
- Story
- Economy values

Champion Tour must establish its own identity.

---

# CEEM Interactive Philosophy

Quality over quantity.

Every feature should:
- Improve player experience
- Be polished
- Be reusable
- Support future Unity migration

Features should never be added simply because another game has them.

---

# Success Criteria

The first public version is considered successful when:

- Football Academy is fully playable.
- All producer levels work.
- Academy renovation is complete.
- Economy is balanced.
- Gameplay feels satisfying without sound effects.

Only after these goals are achieved may development continue to additional sports.
